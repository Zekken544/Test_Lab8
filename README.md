## Дүгнэлт

Mockito mock нь хамаарлын хариуг тохируулж, ямар дуудлага хийгдсэнийг шалгах боломж олгодог. Гараар бичсэн fake нь санах ойд ажиллах сан шиг хялбаршуулсан боловч ажилладаг хэрэгжүүлэлт юм. Энэ лабад repository болон и-мэйл илгээгчийг mock хийснээр бүртгэлийн логикийг тусад нь шалгасан. Шалгаж буй `CourseRegistrationService` болон энгийн `Student` өгөгдлийн объектыг mock хийх шаардлагагүй. `verify` нь бүртгэл хадгалагдсан эсэх зэрэг чухал үйлдлийг батлахад хэрэгтэй. Харин дотоод дуудлага бүрийг шалгавал зан төлөв өөрчлөгдөөгүй кодын засвар ч тестийг унагаж болно. Мутацийн туршилтаар тестүүд шаардлагатай гурван өөрчлөлтийг илрүүлж байгааг баталсан.
